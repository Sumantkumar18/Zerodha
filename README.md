# Zerodha Clone

A full-stack Zerodha-inspired stock trading platform built using React, Node.js, Express, and MongoDB.

## 🚀 Live Demo

### Website

https://zerodhacloner.onrender.com/

### Dashboard

https://zerodhaclonedash-e102.onrender.com/

### Backend API

https://zerodhaclonerb.onrender.com/

---

## 📌 Features

* Responsive Zerodha-inspired landing page
* User authentication
* Holdings dashboard
* Positions and Orders management
* Portfolio analytics
* Interactive charts
* MongoDB database integration
* REST API backend
* React-based frontend
* Separate trading dashboard

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Sumantkumar18/Zerodha.git
cd Zerodha
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

### Dashboard Setup

```bash
cd dashboard
npm install
npm start
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

---

## 🌐 Environment Variables

Create a `.env` file inside the backend folder.

```env
MONGO_URL=your_mongodb_connection_string
PORT=3002
```
